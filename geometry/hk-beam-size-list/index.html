计算公式

  • 理论重量m = ρ·A = 0.785 × A（kg/m，A 单位 cm²）
  • 惯性半径i = √(I / A)
  • 截面模数W = I / (H/2)
  • 翼缘宽厚比HK 系列翼缘较宽，B 通常不小于 H 的 2/3，适合柱与重载梁
